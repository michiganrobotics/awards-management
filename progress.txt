## 2026-01-06 - Status Badge Accessibility Improvements

### Feature: Improve status badge accessibility
Category: accessibility

### Changes Made:
- Updated `components/status-badge.tsx` to be fully accessible for screen readers
- Added `role="status"` attribute to the Badge component for proper ARIA semantics
- Added `aria-label` with descriptive text (e.g., "Nomination status: Successful")
- Added `sr-only` span with full context text for screen readers
- Added `aria-hidden="true"` to the visual text to avoid duplicate announcements
- Added `getTypeLabel()` function to provide context about the type of status (nomination, letter, support letter)
- Added `getScreenReaderText()` function to generate full accessible text

### Accessibility Notes:
- Screen readers will now announce: "[Type] status: [Value]" (e.g., "Nomination status: Pending")
- The visible text label ensures color is not the only indicator of status
- The component already displayed text labels, which satisfies the color requirement
